CRITICAL vsftpd 2.3.4 Backdoor Command Execution
10.0
CVSS v3.1
Port: 21/tcp (FTP)
CVE: CVE-2011-2523
Status: Confirmed Exploited
▸ Description & Evidence

The vsftpd 2.3.4 package contains a backdoor introduced by an unauthorized modification to the source code. When a username containing the string :) is sent, the daemon opens a shell listener on TCP port 6200, providing unauthenticated root access.

# Exploit Evidence

[+] Command shell session 1 opened (192.168.56.102:46821 → 192.168.56.101:6200)

Remediation: Upgrade vsftpd to version 2.3.5 or later. Verify the integrity of any vsftpd installation using known-good checksums from the official distribution.

CRITICAL Samba "username map script" RCE
9.3
CVSS v3.1
Port: 445/tcp (SMB)
CVE: CVE-2007-2447
Status: Confirmed Exploited
▸ Description & Evidence

Samba versions 3.0.20 through 3.0.25rc3 contain a vulnerability in the username map script smb.conf option. When this option is enabled, a user can inject shell metacharacters into the username, causing arbitrary commands to execute as root.

[+] Command shell session 2 opened (192.168.56.102:43812 → 192.168.56.101:4444)
uid=0(root) gid=0(root) groups=0(root)

Remediation: Upgrade Samba to 3.0.25 or later. If upgrade is not possible, disable the username map script option in smb.conf.

CRITICAL DistCC Daemon Remote Code Execution
9.3
CVSS v3.1
Port: 3632/tcp
CVE: CVE-2004-2687
Status: Confirmed Exploited
▸ Description & Evidence

The distccd daemon allows arbitrary command execution without authentication by accepting compilation jobs that contain shell commands. This results in remote code execution as the daemon user.

Remediation: Restrict distccd to trusted IP addresses using --allow flags, or disable the service if not required.
