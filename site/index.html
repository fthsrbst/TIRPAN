THE REACT LOOP

How TIRPAN Thinks

Every decision the agent makes follows the Reason-Act-Observe-Reflect cycle — the same loop a skilled human pentester runs in their head.

R

Reason

Analyze current state, known vulnerabilities, prior tool output. Decide the highest-value next action.

A

Act

Execute a tool: nmap scan, searchsploit lookup, metasploit exploit, shell command, or report generation.

O

Observe

Process tool output, extract findings, update internal state. Raw data becomes structured knowledge.

↺

Reflect

Evaluate progress toward objectives. Update strategy. Loop back to Reason with enriched context.

QUICK START

Up in 3 Steps

Requires Python 3.11+, Nmap 7.94+, Metasploit 6.x, and SearchSploit.

1 Clone & Install
# Clone the repository
$ git clone https://github.com/fthsrbst/tirpan.git && cd tirpan
# Create virtual environment and install
$ python3 -m venv .venv && source .venv/bin/activate
$ pip install -r requirements.txt
2 Configure LLM
# Copy and edit configuration
$ cp .env.example .env
# Set one of these in .env:
OPENROUTER_API_KEY=sk-or-... # Claude, GPT-4, Gemini
OLLAMA_MODEL=llama3.1:8b # Local / air-gapped
3 Launch
# Start Metasploit RPC (required for exploitation)
$ msfrpcd -P your_password -S
# Launch the web UI
$ python3 main.py
# → Open http://localhost:8000
